# Mental Maths

Mobile-first web app for practicing multiplication tables (2–25).

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`) on your phone (same Wi‑Fi) or desktop.

## Build

```bash
npm run build
npm run preview
```

Deploy the `dist` folder to Vercel, Netlify, or Cloudflare Pages and share the link.
